# Hisn al-Muslim data

`hisn-al-muslim.json` is the OpenDua v0.0.4 catalogue, a complete structured
edition of Hisn al-Muslim with 132 chapters, 267 entries, 262 recitations, and
249 audio recordings.

- Catalogue: https://opendua.org/v0.0.4/catalogue.json
- Data licence: https://opendua.org/licence/data
- Audio licence: https://opendua.org/licence/audio

The file is kept locally so the Duas page works in the static export without a
runtime API request. The page links back to the catalogue and displays the
source chapter and entry for every recitation.

`hadith-duas.json` is generated by `scripts/build-hadith-duas.mjs` from the
seven hadith collections already bundled under `public/data/hadith`. The build
scans all 36,390 local hadiths and indexes 506 records whose English text
contains direct supplication or remembrance wording, with a link to the full
hadith reader entry.
